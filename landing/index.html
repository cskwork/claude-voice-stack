Talk to your coding agent.
Your Mac does the listening and speaking.

코딩 에이전트와 말로 일하세요.
듣고 말하는 일은 내 Mac이 맡습니다.

A fork of qwen-audio-agent that replaces the cloud voice model with a small local stack: Silero VAD, Whisper small (MLX) and Supertonic run on Apple Silicon, GLM-5.3-Flash routes the conversation, and your choice of Claude Code, Codex or Pi handles the code.

qwen-audio-agent를 포크해 클라우드 음성 모델 대신 가벼운 로컬 스택을 앞에 둡니다. Silero VAD, Whisper small(MLX), Supertonic은 Apple Silicon에서 돌고, GLM-5.3-Flash가 대화를 라우팅하며, Claude Code, Codex, Pi 중 선택한 에이전트가 코드를 다룹니다.

How it works

동작 방식

Microphone
   ↓ Silero VAD                      local
   ↓ Whisper small · MLX             local STT, Korean + English
   ↓ GLM-5.3-Flash                   remote router: talk, delegate, control
   ↓ qwen-audio-agent Gateway        tasks, permissions, TUI / Web / Desktop
   ↓ ACP adapter → Claude Code / Codex / Pi
   ↓ GLM-5.3-Flash                   one to three spoken sentences
   ↓ Supertonic                      local TTS
Speaker

Spend RAM on speech, not on duplicate reasoning

RAM은 음성에, 추론 중복에는 쓰지 않습니다

No local general-purpose LLM. One speech pipeline holds Whisper small, VAD and Supertonic; the router runs remotely.

로컬 범용 LLM이 없습니다. 음성 파이프라인 하나가 Whisper small, VAD, Supertonic을 들고 있고 라우터는 원격에서 돕니다.

Choose your agent

에이전트를 선택하세요

Set AGENT_PROTOCOL to claude, codex or pi. Claude and Codex keep native approvals. Pi has no approval prompts or Gateway MCP tools.

AGENT_PROTOCOL을 claude, codex, pi 중 하나로 설정하세요. Claude와 Codex는 기본 승인 방식을 유지합니다. Pi는 승인 창과 Gateway MCP 도구를 지원하지 않습니다.

Interrupt freely

언제든 끼어들기

Speaking over the assistant stops playback within the pipeline. The agent task keeps running unless you cancel it.

말하는 도중 끼어들면 재생만 멈춥니다. 취소를 말하지 않는 한 에이전트 작업은 계속됩니다.

Constraints survive the trip

제약 조건이 끝까지 전달됩니다

"Inspect only, don't edit" is written into the delegation objective and checked by the GLM compatibility gate.

"조사만 하고 수정하지 마"가 위임 목표에 그대로 적히고, GLM 호환성 게이트가 이를 검사합니다.

Start

시작하기

Requirements: Apple Silicon Mac, Node 22+, Python 3.10–3.12, Claude Code, Codex or Pi authenticated, a GLM-5.3-Flash Chat Completions endpoint and key.

필요한 것: Apple Silicon Mac, Node 22 이상, Python 3.10–3.12, 인증을 마친 Claude Code, Codex 또는 Pi, GLM-5.3-Flash Chat Completions 엔드포인트와 키.

git clone https://github.com/cskwork/claude-voice-stack.git
cd claude-voice-stack
npm install
npm run voice-agent -- setup        # venv + speech-to-speech + Whisper small + Supertonic + config.env
# fill VOICE_LLM_BASE_URL and VOICE_LLM_API_KEY in ~/.claude-voice-stack/config.env
# set AGENT_PROTOCOL=claude, codex, or pi in config.env
npm run voice-agent -- doctor       # includes the GLM compatibility gate
npm run voice-agent -- start --tui
